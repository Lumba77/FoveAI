VRM Avatar Setup
================

Place your .vrm file in this folder (StreamingAssets).
The VRMAvatarLoader will automatically load it at runtime.

Default expected filename: avatar.vrm

You can get VRM models from:
- VRoid Studio (free): https://vroid.com/en/studio
- VRM Hub: https://hub.vroid.com/en
- Sample models: https://github.com/vrm-c/vrm-specification#samples

After placing the file, update the VRM Filename field on the
VRMAvatarLoader component in the Unity Inspector if using a different name.
