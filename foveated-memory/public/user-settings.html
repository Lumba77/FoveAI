Connect your own cloud API key — the request still runs through the full XRLF pipeline (your memory, compression, persona). The bill goes to your provider, not us.

🔑 Get a free NVIDIA key — no card, ~2 min
  1. Go to build.nvidia.com and sign in (Google/email works).
  2. Open any model page → Get API Key → Generate Key. Copy the nvapi-… key.
  3. Pick NVIDIA NIM below, paste the key, set a default model, save.
Free dev tier — your own allowance, no FoveAI quota used. Models we've verified: nvidia/nemotron-3-super-120b-a12b (big, smart), deepseek-ai/deepseek-v4-flash-0731 (fast coder), openai/gpt-oss-20b (small, quick). Any model id from build.nvidia.com works via byok/<model>.
Use in chat/model pickers as byok (your default model) or byok/<model>.
