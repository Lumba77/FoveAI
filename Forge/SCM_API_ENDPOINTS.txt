# Smart Context Manager API Endpoints

These endpoints have been added to forge_api.py for the Smart Context Manager:

## POST /api/context/report-tokens
Report token count and receive context recommendations.
Request body: {"token_count": 35000, "session_id": "...", "metadata": {...}}
Response: ContextRecommendation object with action, priority, suggestions

## POST /api/context/burst-mode  
Request burst mode for complex tasks.
Request body: {"reason": "multi_file_refactoring", "custom_turns": 5}
Response: {"granted": true, "recommendation": {...}}

## POST /api/context/exit-burst
Exit burst mode and return to normal limits.
Response: ContextRecommendation

## POST /api/context/apply-cutting
Apply tiered context cutting to messages.
Request body: {"session_id": "...", "messages": [...], "tier": "tier_2"}
Response: {"processed_messages": [...], "metadata": {...}}

## GET /api/context/session/{session_id}
Get context state for a session.
Response: SessionContextState dict

## GET /api/context/stats
Get overall Smart Context Manager statistics.

## POST /api/context/quality-signal
Report quality signals for context-aware decisions.
Query params: session_id, signal_type (tool_success|tool_failure|correction|repeat_attempt)
