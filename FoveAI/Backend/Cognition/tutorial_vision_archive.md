# Seamless Interactive Tutorial (Vision Archive)

**Date Logged:** 2026-07-06
**Subject:** The Director as a Setup Host
**Status:** Archived for Future Implementation (Librarian Tracking)

## Concept Overview
The user described a brilliant, seamless onboarding experience for first-time users. Instead of navigating a sterile HTML settings menu, the user enters a "void" where the **Director Manager** (acting as an unseen studio host/game master) directly speaks to them.

## The Flow
1. **The Void:** The game starts in an empty or abstract space.
2. **The Voice:** The Director Manager's voice asks questions dynamically generated by the cloud LLM. 
   - *"How do you want to look today?"*
   - *"What kind of experience are you seeking? Is this a practical AI assistant, an organic companion, or something in between?"*
3. **Interactive Setup:** As the user answers (via voice), the Director dynamically pulls the levers—adjusting the Avatar's appearance, setting the `jen_soul.json` system prompt (Companion vs. Assistant), and altering the environment.
4. **Seamless Transition:** Once the setup is complete, the void fades into the actual 3D environment, and the game begins without the user ever feeling like they were in a "Settings Menu".

## Historical Context
This vision was originally implemented and utilized but was lost during a previous architecture migration. Because it relied heavily on generative AI and required significant cloud API token usage, it was difficult to maintain.

## Future Implementation Notes
When we are ready to rebuild this:

- This should be built as a distinct "Scene" in the `WebXRChatbot.js` routing logic.
