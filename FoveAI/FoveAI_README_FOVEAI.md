# FoveAI Workspace Target

This directory contains the refactored **FoveAI** spatial AI application.

## Structure
- `backend/`: Async Python Engine (Foveated Memory, The Director, Multi-LLM Router, IPC).
- `client_quest/`: Unity C# OpenXR Client for Meta Quest 3 Passthrough AR.
- `client_desktop/`: PC Control & Monitoring TUI.
- `schemas/`: Shared JSON contracts for client-server IPC and memory data formats.
